# Local temporary files

List files and inspect ownership, size and purpose before selecting removals. Read setup and CI scripts before running them; they change local state.

Keep runtime sockets and PID files, private credentials, database backups and retained review evidence. A generic folder name does not make data disposable. Clean only your own task scratch files. Unique untracked evidence or another session's files need an exact reviewed list and missing authority. Stop only processes you started. Report what was removed and preserved. Never run a blanket `rm` on tmp or runtime directories.
